# Local fonts

These unmodified variable fonts are loaded through `next/font/local` in
`src/fonts.ts` so development and production builds do not fetch Google Fonts.
Both include Latin and Cyrillic glyphs, including Ukrainian characters.

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Geist Mono: https://github.com/google/fonts/tree/main/ofl/geistmono

Each font's SIL Open Font License is included in its directory as `OFL.txt`.
